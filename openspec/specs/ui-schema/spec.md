# ui-schema Specification

## Purpose

定义插件描述界面所用的 JSON 结构——有哪些组件、每个组件接受什么属性、交互事件的载荷长什么样——使插件在不接触 DOM 的前提下能够表达界面，且这份表达可被序列化、校验与快照测试。

## Requirements

### Requirement: 界面由节点树描述且节点结构固定

界面 SHALL 由一棵 JSON 节点树描述。每个节点 SHALL 由五个字段构成：`type`（组件类型）、`id`（视图内唯一标识）、`props`（组件属性）、`children`（仅容器类组件有）、`on`（事件名到动作字符串的映射）。

`type` 与 `id` MUST 存在；其余字段可省略。

`on` 中的动作字符串由插件自定义，宿主 MUST 原样透传，MUST NOT 解释其含义。

#### Scenario: 最小合法节点

- **WHEN** 节点只有 `type` 与 `id`
- **THEN** 该节点合法

#### Scenario: 动作字符串被透传

- **WHEN** 节点声明 `"on": {"click": "任意自定义动作名"}`
- **THEN** 该字符串在事件回传时原样出现，宿主不对其做任何校验或转换

### Requirement: 组件类型限定于已定义的清单

`type` MUST 属于已定义的组件清单，覆盖五个类别：布局、展示、输入、数据、反馈。

组件清单的每一项 SHALL 有明确的属性契约，规定各属性的名称、类型与是否必需。

#### Scenario: 已知组件通过校验

- **WHEN** 节点 `type` 为清单中的任一组件且属性符合其契约
- **THEN** 校验通过

#### Scenario: 属性类型不符被报告

- **WHEN** 某组件的数值型属性被赋予字符串
- **THEN** 校验报告该节点的该属性类型不符

### Requirement: 未知组件类型必须局部降级而非整树拒绝

节点的 `type` 不在已定义清单中时，校验 SHALL 将该节点标记为需要降级渲染，并产生一条警告。

该节点的存在 MUST NOT 导致整棵树被拒绝——同一棵树中其余合法节点 SHALL 照常可渲染。

#### Scenario: 单个未知节点不影响兄弟节点

- **WHEN** 一棵树中有一个未知类型的节点和三个合法节点
- **THEN** 校验结果标记该节点需降级，另外三个节点正常
- **AND** 产生一条警告，不产生错误

#### Scenario: 未知节点的子树一并降级

- **WHEN** 未知类型的节点带有 `children`
- **THEN** 该节点整体降级，其子树不被单独渲染

### Requirement: 节点标识在视图内唯一且跨重绘稳定

同一视图的一棵树中，`id` MUST 唯一。

`id` 的跨重绘稳定性由插件作者保证——它是渲染差异比对、焦点保持与滚动位置保持的依据。校验 SHALL 在同一棵树中检出重复 `id` 并产生警告。

#### Scenario: 重复 id 被检出

- **WHEN** 一棵树中两个节点使用相同的 `id`
- **THEN** 校验产生警告，指出重复的 `id` 与所在位置

### Requirement: 交互事件的载荷形状固定

用户交互 SHALL 被打包为含四个字段的结构：`nodeId`、`event`、`action`、`value`。

无值的交互 `value` 为空；带值的交互在 `value` 中携带该组件类型规定的载荷。

#### Scenario: 无值交互

- **WHEN** 用户点击按钮
- **THEN** 事件载荷含该按钮的 `nodeId`、事件名 `click`、节点声明的动作字符串，`value` 为空

#### Scenario: 带值交互

- **WHEN** 用户在文本输入框中提交内容
- **THEN** `value` 中携带输入的文本

#### Scenario: 表格行交互携带结构化载荷

- **WHEN** 用户点击表格的某一行
- **THEN** `value` 中同时携带行序号与该行的数据

### Requirement: 文件选择交付标识而非路径

文件选择组件的事件载荷 MUST 携带一个交付标识、文件名与字节数，MUST NOT 携带任何真实文件路径。

插件凭该交付标识从自身私有存储的保留命名空间读取内容。文件选择 MUST NOT 要求插件持有任何文件系统权限。

#### Scenario: 载荷不含路径

- **WHEN** 用户通过文件选择组件选定一个文件
- **THEN** 事件载荷含交付标识、文件名与大小，不含目录或绝对路径

#### Scenario: 无文件系统权限也可用

- **WHEN** 一个未声明任何文件系统权限的插件使用文件选择组件
- **THEN** 该组件正常工作，插件能取到文件内容

### Requirement: 输入组件不提供凭据输入形态

文本输入组件 MUST NOT 提供密码或掩码形态的属性。

需要凭据的场景 SHALL 通过插件配置项表达——那里由宿主统一施加掩码呈现、日志脱敏与风险说明，而插件的界面描述树中无法强制这些保护。

#### Scenario: 掩码属性不存在

- **WHEN** 插件尝试为文本输入组件声明密码形态
- **THEN** 校验失败，因为该属性不在组件契约中
